# 当前状态与接手

本仓库是当前独立系统的公开可维护快照，基于已完成的模块化重构成果整理；历史过程留在原工作区，首次公开提交不是此前全部开发历史。

## 已有能力与验证方向

模块/接口/事件/事务及51表目录保持现有业务。入口默认合成管理员、7天会话与自动恢复；通知为Fake。公开整理新增本仓库独立安装/初始化/运行/验证/打包工具，并将“旧版基线”辅助链接替换为本仓库项目说明。

自动关卡见 `scripts/verify.py` 和GitHub Actions：类型/构建、生成契约、模块依赖、UI模板样式基线、公开文件边界、供应方MockTransport、真实独立PG的项目工作/需求交付/管理统计/完整链路和入口测试。测试与业务接受、真实投递、发布状态分别报告。

## 明确限制

- 公开部署使用合成数据，不包含公司历史业务库接管。
- 钉钉适配器已实现与协议模拟验证；实际企业凭据、应用权限和消息抵达未联调。
- 公开演示默认管理员，不是企业账号密码或多租户产品。
- 普通事件没有完整outbox或严格一次保证；恢复/去重只对已证明持久来源成立。
- 通用知识库是原范围示例页，运营知识有真实持久记录。
- 依赖保留主版本体系并已做semver范围内兼容修复；npm audit仍有9个受影响开发/构建依赖节点（6 high、3 moderate），详见[SECURITY](../SECURITY.md)，本次迁移不等于安全审计全部通过。
- 目录检查不是自动迁移体系；既有字段/历史兼容仍需维护。
- 新功能/修复需按CONTRIBUTING更新具体契约与验证，不重新引入旧版隐式依赖。

## 接手顺序

README → PRODUCT_BASELINE → ARCHITECTURE/MODULES → 受影响API/EVENTS/DATA_MODEL → 实际代码与测试。先独立运行验证，再讨论新的范围。根目录AGENTS适用于AI协作，规范不依赖私人skills或聊天记录。

发布版本应关联Git提交和部署包manifest；当前线上地址暂保持原发布，公开仓库不会自行替换服务器数据。实测结果汇总在 [VERIFICATION](VERIFICATION.md)。
